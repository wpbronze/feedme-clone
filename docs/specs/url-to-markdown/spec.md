# URL to Markdown 변환기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여주고, 복사·다운로드하거나 ChatGPT·Claude로 바로 넘기는 단일 화면 서비스입니다.

## 연결된 소스

- [prototype.html](prototype.html): 승인된 화면입니다. 화면 배치(URL 입력창 아래에 프롬프트·내보내기 패널, 그 아래에 결과), 기본·변환 중·결과·오류 상태, 다크모드 토글 위치를 정합니다. 데이터와 동작은 더미이므로 실제 변환·클립보드·새 탭 열기는 이 스펙의 본문이 정합니다.
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md): 화면 구성, 상태 설계, 반응형의 기준입니다. 이 스펙은 규칙을 다시 적지 않고 따릅니다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md): 새 의존성을 추가할 때 버전 정책의 기준입니다.
- defuddle 문서: https://defuddle.md/docs

## 사용자에게 보이는 결과

1. **입력.** 사용자가 URL 입력창에 주소를 붙여넣고 변환합니다. 지우기 버튼을 누르면 입력, 결과, 오류, 프롬프트 선택이 모두 초기 상태로 돌아갑니다.
2. **변환.** 입력한 페이지의 본문을 Markdown으로 추출합니다. 변환 중에는 진행 상태가 보입니다.
3. **결과 확인.** 결과 영역 위쪽에 페이지 제목과 저자 헤더가 나오고, 그 아래에 렌더링된 Markdown이 나옵니다. 저자 정보가 없는 페이지는 저자 줄만 생략합니다.
4. **내보내기.**
   - 복사하기: Markdown 원문을 클립보드에 복사하고, 복사됐다는 피드백을 보여줍니다.
   - .md 다운로드: Markdown 원문을 `.md` 파일로 내려받습니다. 파일명은 페이지 제목에서 만들고, 제목이 없으면 기본 이름을 씁니다.
   - ChatGPT로 열기 / Claude로 열기: `[프롬프트 + 빈 줄 + Markdown]` 전체를 클립보드에 복사하고 해당 서비스(`chatgpt.com`, `claude.ai/new`)를 새 탭으로 엽니다. 프롬프트를 고르지 않았으면 Markdown만 복사합니다. 사용자가 새 탭에서 붙여넣기만 하면 되도록, 버튼을 누른 화면에 "클립보드에 복사했습니다. 열린 탭에서 붙여넣기 하세요" 안내를 보여줍니다.
5. **프롬프트(선택).**
   - 프리셋: 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘 중 하나를 고르면 LLM 전달 시 Markdown 앞에 붙습니다. 고르지 않은 상태가 기본이고, 이미 고른 프리셋을 다시 누르면 선택이 해제됩니다.
   - 직접 입력: 프리셋 옆의 "직접 입력"을 선택하면 텍스트 입력창이 나타나고, 입력한 문장이 같은 방식으로 앞에 붙습니다. 입력이 비어 있으면 아무것도 붙이지 않습니다.
   - 프롬프트는 복사하기와 다운로드에는 영향을 주지 않으며, 어디에도 저장하지 않습니다. 새로고침하거나 지우기를 누르면 사라집니다.
6. **다크모드.** 화면 어디서든 보이는 토글로 라이트와 다크를 전환합니다. 처음에는 OS 설정을 따릅니다.

## 승인된 범위

- 화면 배치는 위에서 아래로 헤더(다크모드 토글 포함), URL 입력창과 변환 버튼, 프롬프트·내보내기 패널, 결과 순서입니다. 패널은 변환 전에도 보이되 내보내기 버튼은 결과가 있을 때만 활성화됩니다. 좁은 화면에서도 같은 순서로 쌓입니다.
- 단일 페이지 하나로 구성합니다.
- 변환은 defuddle 라이브러리로 합니다(필수). 서버에서 URL을 가져와 변환하고 결과를 화면에 돌려줍니다.
- 한 번에 URL 한 개만 처리합니다.

## 수용 기준

1. 올바른 기사 URL(예: `https://stephango.com/file-over-app`)을 변환하면 제목, 저자 헤더와 렌더링된 Markdown 본문이 보입니다.
2. 저자가 없는 페이지는 저자 줄 없이 제목만 보이며 오류가 나지 않습니다.
3. 지우기 버튼은 입력값, 결과, 오류, 프리셋 선택, 직접 입력 텍스트를 모두 초기화합니다.
4. 복사하기로 복사한 내용은 화면에 렌더링된 Markdown의 원문과 같고, 프롬프트는 포함하지 않습니다.
5. .md 다운로드는 같은 원문을 `.md` 파일로 내려받습니다.
6. 프리셋이나 직접 입력을 고른 뒤 ChatGPT·Claude 버튼을 누르면 클립보드 내용이 `프롬프트 + 빈 줄 + Markdown` 순서이고, 해당 서비스가 새 탭으로 열립니다. 프롬프트가 없으면 Markdown만 복사됩니다.
7. "직접 입력"을 선택해야 텍스트 입력창이 보이고, 다른 프리셋을 고르면 사라집니다. 입력한 내용은 새로고침 후 남아 있지 않습니다.
8. 빈 입력, `http`·`https`가 아닌 주소, 접속할 수 없는 페이지, 본문을 추출하지 못한 페이지는 각각 이해할 수 있는 오류 메시지로 보이고, 내보내기 버튼은 비활성화됩니다.
9. 다크모드 토글이 라이트와 다크를 전환하고, 두 모드 모두에서 모든 상태(입력, 로딩, 결과, 오류)가 읽을 수 있게 보입니다.
10. 좁은 화면에서도 모든 버튼이 숨겨지지 않고 쌓여서 보입니다.

## 확정된 제약과 근거

- **LLM 전달은 클립보드 + 새 탭으로 한다.** ChatGPT·Claude의 `?q=` 주소 파라미터는 공식 길이 한도 문서가 없고, 제3자 자료는 2,000～6,000자를 권합니다. Claude 웹은 파라미터가 제거됐다는 보고도 있습니다(anthropics/claude-code#8827). 기사 본문은 이 한도를 쉽게 넘으므로, 글 길이와 무관하게 동작하는 클립보드 방식으로 정했습니다. 다시 검토할 조건은 두 서비스가 긴 프롬프트를 받는 공식 주소 규약을 문서화했을 때입니다.
- **defuddle은 Node 쪽에서 쓴다.** 공식 문서의 `defuddle/node`에 DOM 구현(linkedom)을 함께 쓰는 방식입니다. 브라우저에서 임의 사이트를 직접 가져오면 CORS로 막히므로 서버에서 가져옵니다. 호스티드 `defuddle.md` API가 아니라 라이브러리를 쓰는 것이 요구사항입니다. 임시 폴더에서 `defuddle@0.19.6` + `linkedom`으로 `markdown: true` 변환이 제목, 저자, Markdown 본문을 돌려주는 것을 확인했습니다.
- UI는 [ui-composition](../../decisions/ui-composition.md)을 따라 shadcn 구성과 semantic token으로 만들고, 로딩·오류·비활성 상태를 정상 화면과 함께 설계합니다.

## 가정(바꿔도 되는 기본값)

- 프롬프트가 있을 때 결합 형식은 `프롬프트 + 빈 줄 + Markdown`입니다.
- 다크모드 선택은 이 브라우저에 유지해도 되고, 프롬프트와 변환 결과는 저장하지 않습니다.
- 변환 결과는 Markdown 본문만 다루고, 이미지는 원본 주소를 그대로 가리킵니다.
- 로그인이 필요한 페이지, 자바스크립트로만 그려지는 페이지는 본문을 못 얻을 수 있으며, 이 경우 추출 실패 오류로 처리합니다.

## 남은 위험

- 클립보드 방식은 사용자가 직접 붙여넣어야 합니다. 안내 문구가 눈에 띄지 않으면 붙여넣기를 놓칠 수 있습니다.
- 사이트에 따라 본문 추출 품질이 달라집니다. defuddle의 결과를 그대로 신뢰합니다.
- 브라우저가 클립보드 쓰기를 거부하면(권한, 비보안 컨텍스트) 복사 계열 동작이 실패합니다. 이 경우 실패했다는 안내를 보여줍니다.
