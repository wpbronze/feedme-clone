# 웹 페이지 Markdown 추출

## Decisions

- 웹 페이지 본문 추출은 `defuddle` 라이브러리로 하고, Node 쪽에서 `defuddle/node`에 DOM 구현(`linkedom`)을 함께 써서 `markdown: true`로 변환합니다.
- URL은 서버에서 가져와 변환하고 결과만 화면에 돌려줍니다.
- 호스티드 `defuddle.md` API는 쓰지 않습니다.
- 이미지는 변환하지 않고 원본 주소를 그대로 가리킵니다.

## Boundaries

- 로그인이 필요한 페이지와 자바스크립트로만 그려지는 페이지는 본문을 못 얻을 수 있습니다. 이 경우는 추출 실패 오류로 처리하고 우회하지 않습니다.

## Why

브라우저에서 임의 사이트를 직접 가져오면 CORS로 막히므로 서버에서 가져와야 합니다. 라이브러리를 쓰는 것은 요구사항이며, `defuddle@0.19.6` + `linkedom` 조합이 제목, 저자, Markdown 본문을 돌려주는 것을 임시 폴더에서 확인했습니다.
