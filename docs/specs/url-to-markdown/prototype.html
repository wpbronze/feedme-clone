파일이 앱보다 중요하다 (File over app)

Steph Angostephango.com376단어

File over app은 하나의 철학입니다. 오래 남는 디지털 결과물을 만들고 싶다면, 직접 통제할 수 있고 쉽게 꺼내 읽을 수 있는 형식의 파일이어야 합니다.

왜 파일인가

모든 소프트웨어는 언젠가 사라집니다. 앱이 사라져도 파일은 남아야 합니다.

  • 파일은 사람이 읽을 수 있어야 합니다
  • 특정 회사의 서버에 묶이지 않아야 합니다
  • 수십 년 뒤에도 열려야 합니다
앱은 일시적이지만 파일은 오래 갑니다.

예시

notes/
  2026-11-18-ideas.md
  reading-list.md

이 폴더는 어떤 편집기로 열어도 .md 파일 그대로 읽힙니다.
