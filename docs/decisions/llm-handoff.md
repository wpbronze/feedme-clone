# LLM 서비스로 내용 넘기기

## Decisions

- ChatGPT·Claude로 내용을 넘길 때는 `[프롬프트 + 빈 줄 + Markdown]` 전체를 클립보드에 복사하고 해당 서비스(`chatgpt.com`, `claude.ai/new`)를 새 탭으로 엽니다. 사용자는 새 탭에서 붙여넣기만 합니다.
- 버튼을 누른 화면에는 "클립보드에 복사했습니다. 열린 탭에서 붙여넣기 하세요" 안내를 보여줍니다. 클립보드 쓰기가 거부되면 실패했다는 안내를 보여줍니다.
- 프롬프트가 없으면 Markdown만 복사합니다. 프롬프트는 일반 복사와 다운로드에 포함하지 않고, 어디에도 저장하지 않습니다.

## Boundaries

- 넘기는 내용의 종류나 프롬프트 프리셋 목록을 정하는 결정이 아닙니다. 전달 방식만 정합니다.

## Why

기사 본문은 주소 파라미터(`?q=`)에 담기에는 너무 깁니다. 두 서비스 모두 공식 길이 한도 문서가 없고, 제3자 자료는 2,000～6,000자를 권합니다. Claude 웹은 파라미터가 제거됐다는 보고도 있습니다(anthropics/claude-code#8827). 클립보드 방식은 글 길이와 무관하게 동작합니다.

## Reconsider when

- ChatGPT 또는 Claude가 긴 프롬프트를 받는 공식 주소 규약을 문서화했을 때

## Still-rejected alternatives

- `?q=` 주소 파라미터로 본문을 직접 전달하는 방식 — 한도가 불명확하고 긴 글에서 잘리거나 무시됩니다.
